# SSH / Shell Access Boundary

## 结论

本项目不会教用户通过漏洞、破解或绕过厂商安全限制来获取 SSH/root。

### 官方已支持网易 UU远程的路由器

如果设备已经通过厂商固件或网易官方入口支持 UU远程 / WOL，请优先使用官方方式。通常不需要为了本项目额外开启 SSH。

### 需要社区手动适配的路由器

只有在用户已经通过合法、明确、可恢复的方式取得 SSH 或等效 root Shell 后，才进入本项目的手动安装与诊断流程。

## 用户应该去哪里查 SSH 开启方式

优先级：

1. 路由器厂商官方文档；
2. 当前固件项目官方文档（例如 OpenWrt、ASUSWRT-Merlin 等）；
3. 本仓库对已经真实验证设备提供的型号说明；
4. 社区资料仅作为补充，并应自行核对版本、风险与回滚方式。

本项目不会提供“通用 SSH 破解教程”，因为不同品牌、型号、固件版本的风险差异很大。

## 为什么要设这条边界

远程 WOL 适配本身只需要解决：

- 平台识别；
- 官方 UU 插件获取；
- 持久化；
- 健康检查；
- 账号绑定；
- WOL 验收。

“如何突破厂商安全边界拿到 root”是另一类问题，不应该和本项目绑定在一起。
