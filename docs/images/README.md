# README 配图来源与性质

以下图片用于帮助新手理解软件功能和操作路径。**除单独说明的真实设备截图外，本套 PNG 不是操作系统或软件的原始截图，也不是安装成功的证据。**

| 文件 | 来源 | 使用说明 |
|---|---|---|
| `uu-doc-00-overview.png` | 独立设计制作的概览插图 | 不是软件截图，不表示任何路由器已经通过远程唤醒验证 |
| `uu-doc-01-download.png` | 按 GitHub “Code → Download ZIP” 下载操作绘制 | 操作示意图，不是 GitHub 网页原始截图 |
| `uu-doc-02-windows.png` | 根据 `tools/windows-launcher.ps1` 当前真实提示文字排版 | 模拟 Windows 命令行示例，`router.example.invalid` 是测试域名；不表示连接过真实路由器 |
| `uu-doc-03-openwrt-qemu.png` | 根据 GitHub Actions [QEMU ARM64 Lab 测试记录](https://github.com/coolhpj/uu-remote-wol-router-helper/actions/runs/38160517622) 的实际 OpenWrt 串口日志内容排版 | 保留 `linux,dummy-virt` / `openwrt` / `aarch64` 及当次菜单文字；这是排版图，不是虚拟机屏幕截图 |

仓库中原有 `uu-openwrt-device.webp` 为真实环境下网易 UU 识别辅助设备的脱敏截图，与以上四张示意图性质不同，应保留原始来源。

**兼容性证据以真实设备、手机移动数据远程开机结果及正式测试记录为准；不能用排版图或虚拟机菜单代替实机验收。**
